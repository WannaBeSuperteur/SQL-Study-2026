## 1. 기본 함수 설명

* 함수 설명

| 함수           | 설명                                                         |
|--------------|------------------------------------------------------------|
| `DATE_ADD`   | ```value``` 에 날짜 더하기, ```DATE_ADD(value, interval time)``` |
| `DATE_SUB`   | ```value``` 에서 날짜 빼기, ```DATE_SUB(value, interval time)``` |
| `NOW`        | 현재 시각 (timestamp) 출력                                       |
| `INTERVAL`   | `DATE_ADD`, `DATE_SUB` 에서 가감할 시간을 나타내는 함수                  |
| `CONVERT_TZ` |                                                            |

## 2. 함수 사용 예시

### 2-1. `DATE_ADD`, `DATE_SUB`

* 예시
  * 첫 출근 (```first_go_work```) 은 입사 9시간 후
  * 업무 교육 시작 (```education_start```) 은 입사 1일 후
  * 수습 종료 (```probation_end```) 는 입사 3개월 후
  * 입사 1주년 (```first_anniversary```) 는 입사 1년 후
  * 최종 합격 통보 (```final_accepted```) 는 입사 14일 (2주) 전

```sql
SELECT mle_id,
	   hire_date,
	   eval_date,
	   DATE_ADD(hire_date, interval 9 hour) as first_go_work,
	   DATE_ADD(hire_date, interval 1 day) as education_start,
	   DATE_ADD(hire_date, interval 3 month) as probation_end,
	   DATE_ADD(hire_date, interval 1 year) as first_anniversary,
	   DATE_SUB(hire_date, interval 14 day) as final_accepted
FROM probation_data
```

## 3. TimeZone 변환

* TimeZone 변환을 위해서는 ```CONVERT_TZ``` 함수를 사용한다.
* `CONVERT_TZ` 함수는 다음과 같은 형식으로 사용할 수 있다.
  * `CONVERT_TZ(timestamp, '+nn:00', '+mm:00')`
  * `+nn:00` 시간대로 표시된 시각을 `+mm:00` 시간대로 변경한다.
* 예시

```sql
SELECT mle_id,
	   last_commit_timestamp,
	   CONVERT_TZ(last_commit_timestamp, '+00:00', '+09:00') as last_commit_timestamp_kst
FROM probation_data
```
